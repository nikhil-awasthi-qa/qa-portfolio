Sample bug reports (Amrutam)

WEB-001: OTP can be resent repeatedly without a cooldownMedium
Steps
Open the Login page. Enter a valid 10-digit mobile number and request an OTP. On the OTP screen, tap Resend OTP several times within a few seconds.
Expected
Resend is rate-limited with a timer, and repeated requests are blocked for a while.
Actual
Every tap sends a new OTP immediately and shows "OTP resent successfully!" again. No limit applies.
WEB-006: Name fields accept whitespace-only inputMedium
Steps
Log in. Open Profile, then Edit Profile. Enter only spaces in First Name and Last Name. Save.
Expected
The input is rejected as empty or invalid.
Actual
The profile saves, and the name fields look blank. Numeric-only names were also accepted (WEB-005).
MOB-004 (Android): Profile update blocked by a State field that does not existMedium
Steps
Log in. Open Edit Profile. Update the profile details. Tap Update Profile.
Expected
The profile updates, or a required State field is visible and editable.
Actual
The update fails with "State cannot be empty." although the screen has no State field.

Steps

Actual
